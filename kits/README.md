# Kit archives

The delivery helper attaches a zip that already exists on disk. It does not create product files.

| Tier | Put the real archive here |
| --- | --- |
| Starter (29 USDT) | `kits/client-closer-kit-starter.zip` |
| Complete (47 USDT) | `kits/client-closer-kit-complete.zip` |

If a zip is missing, read the matching `*.zip.PLACEHOLDER.md` in this folder. Those notes are path markers, not the kit.

`kits/*.zip` is listed in `.gitignore`. Do not commit the paid archives while this site is public.
